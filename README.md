# VS Code Settings

## Quick install

```bash
curl -fsSL https://raw.githubusercontent.com/vndly/claude-code-settings/main/install.sh | bash
```

## Manual install

1. Clone the repository
2. Run the command `./deploy.sh`
  * This command copies the following items to the folder `~/.claude`:
    * File `settings.json`
    * File `CLAUDE.md`
    * Folder `data`
    * Folder `scripts`
